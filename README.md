# クレジットカード利用通知システム

クレジットカードの利用通知メールをGmailから取得し、利用情報をGoogleスプレッドシート、Slack、Googleカレンダーに連携するGoogle Apps Scriptアプリケーションです。メールファイルをローカルで復号するPythonスクリプトも含みます。

## 主な機能

- Gmailからカード利用通知を取得し、利用日・利用先・金額などを抽出
- 利用明細をGoogleスプレッドシートに記録し、カード別・月別に集計
- カード利用情報をSlackに通知
- 利用情報をGoogleカレンダーに登録
- メールファイルをローカルで復号

## 対応カード

- **JCBグループ**: リクルートカード、JCB CARD Wなど
- **三井住友カード (SMBC)**: 三井住友カードVISAなど
- **ビューカード (VIEW)**: ビューカード系列

各カード会社のメール形式に応じたパーサーを実装しています。

## 構成

```text
.
├── decode_email.py          # メールファイルのローカル復号
├── Pipfile                  # Python実行環境の設定
└── src/
    ├── main_controller.js   # GASのエントリーポイント
    ├── card_controller.js   # カード会社別の解析と処理
    ├── gmail_controller.js  # Gmail連携
    ├── slack_controller.js  # Slack通知
    ├── sheet_controller.js  # スプレッドシート操作
    └── calendar_controller.js # Googleカレンダー連携
```

## セットアップ

### Google Apps Script

1. Google Apps Scriptでプロジェクトを作成し、`src/`のスクリプトを登録します。
2. 通知先のGoogleスプレッドシートに「カード情報」「利用明細」「更新情報」の各シートを用意します。
3. スクリプトプロパティに以下を設定します。
   - `SLACK_BOT_TOKEN`: SlackボットのOAuthトークン
   - `CALENDAR_ID`: 通知を登録するGoogleカレンダーのID
4. Slackボットに、通知先チャンネルへの投稿権限を付与します。
5. `main_new()`を定期実行するトリガーを設定します。

### メール復号スクリプト

Python 3.15を使用します。追加のPythonパッケージは不要です。メールファイルのパスを引数に指定して実行します。

```sh
python3 decode_email.py path/to/email.eml
```

復号した本文は入力ファイルと同じフォルダーに`email.decoded.txt`の形式で出力されます。入力ファイルは変更されません。

## 使い方

### Googleスプレッドシート

「更新情報」シートの1行目を見出しにし、2行目以降に監視対象を登録します。

| 列 | 内容 |
| --- | --- |
| A | カード会社・ブランド |
| B | Gmailの検索条件およびメール件名 |
| C | 最終利用日 |
| D | メール形式の識別子 |

「カード情報」シートは次の列構成です。

| 列 | 項目 |
| --- | --- |
| A | カード名 |
| B | ご利用金額 |
| C | カード合計初日 |
| D | カード合計末日 |
| E | 時計算用 |
| F | ブランド |
| G | 絵文字 |
| H | 前月のご利用金額 |
| I | 前月のカード合計初日 |
| J | 前月のカード合計末日 |
| K | 前月までの1年間のご利用金額 |
| L | 前月までの年間合計初日 |
| M | 前月までの年間合計末尾 |

「利用明細」シートには、処理された利用日、金額、カード名、利用先、利用取引が自動で追記されます。

### Google Apps Script

1. Apps Scriptのエディタで`main_new()`を実行し、Gmail、スプレッドシート、Slack、カレンダーへのアクセスを承認します。
2. 動作を確認したら、`main_new()`を定期実行する時間主導型トリガーを設定します。
3. 実行のたびに「更新情報」シートの条件でメールを検索し、利用情報を「利用明細」へ記録します。最終利用日も更新され、Slack通知とカレンダー登録が行われます。

メール形式の識別子には、`CardController.CARD_RECEIVES`で定義されている値を指定してください。

## 運用とカスタマイズ

- Gmailの検索条件やカード会社ごとの監視設定は、スプレッドシートの「更新情報」シートで管理します。
- 最終処理日を記録し、同じ利用通知の重複処理を防ぎます。
- 新しいカード会社に対応する場合は、`CardController.CARD_RECEIVES`にメール形式に応じた解析処理を追加します。
- 大量のメール処理には時間がかかる場合があります。Google Apps Scriptの実行時間制限にもご注意ください。
- 個人情報を扱うため、スプレッドシートとスクリプトのアクセス権限を適切に設定してください。
